# Neuva Morpheus8 Cool promo

Open `morpheus8-cool-preview.html` in a browser to review the layout.

To use it in Divi:

1. Open the Promos page in the Divi Builder.
2. Add a Code Module where the promotion belongs, or replace the old promotion's Code Module.
3. Paste the entire contents of `morpheus8-cool-code-module.html`, including the `<style>` block.
4. For the intended desktop width, set the containing row to **Width: 100%** and **Max Width: 1120px**. Reduce the row's horizontal padding if the module feels narrow on mobile.
5. Preview desktop and mobile before saving the page.

The module uses the existing site's fonts when available, with system fallbacks. Its styles are scoped to `#neuva-cool-promo`. It does not include a duplicate page title, site header, or footer. The preview adds only a neutral page surround.

The Instagram destination is the account linked from https://neuvaaesthetics.com/: `https://www.instagram.com/neuva_aesthetics/`. The telephone link uses the standard `tel:` format; the displayed number and all promotional wording match the supplied text. “Small print:” is retained literally to preserve the requested wording.

This is a local HTML deliverable. No WordPress content has been changed or published.
